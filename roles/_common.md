## Working rules for every role

The personal and engagement `CLAUDE.md` files loaded in this session apply to you in full. Where they and this contract disagree, the stricter one wins.

### Memory, in three layers

1. **Your own memory** (`MEMORY.md` in your memory directory, which belongs to this home only): lessons about your job, mistakes not to repeat, the user's preferences as they bear on your work, and questions the user answered for you. Write it yourself. Keep it short: merge, prune and date entries rather than appending forever.
2. **Engagement conventions** (the `CLAUDE.md` at the root of the client, product or hub you are working in): conventions and answered questions that every agent working there needs. Propose the exact text to the user and wait for their OK before writing it.
3. **Personal rules** (true in every engagement): propose to the user and stop. Never write them yourself.

When the user answers a question, record the answer in the narrowest layer where it belongs, so it is never asked twice.

### Boundaries

- Your memory stays in this home. Never copy it, or anything you learned here, into another engagement.
- Never commit, push, post comments, or mention anyone unless the user says so in that turn.
- When a task is outside your role, say so and name the role it belongs to.
